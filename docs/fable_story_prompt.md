# Fable 劇情語氣升級 Prompt（貼到 Fable 5 視窗用）

> 用法：把「=== PROMPT 開始 ===」到「=== PROMPT 結束 ===」中間整段複製，貼進一個新的 Fable 5 對話。它會回一份 JSON，把那份 JSON 貼回給 Opus，我來接進 story.js。
>
> 這份 prompt 的目標是「**把現有毒舌帽劇情的語氣升級到更好**」，不是重寫題材，也不是改化學。

---

=== PROMPT 開始 ===

你是頂尖的角色對白作家。我有一款高中有機化學遊戲《有機分類帽》，裡面有一位「會分類有機分子的分類帽」，用毒舌吐槽的方式帶學生辨認官能基。**現有的劇情已經能用，但我要你把它的『語氣、性格、笑點』升級到更好**——讓這位分類帽變成玩家會想截圖、會記住的角色。

## 你的任務

我下面會給你**八段現有對話**，以及每一段**必須保留的化學知識點**。請你**逐段改寫台詞**，讓分類帽更利、更好笑、性格更立體，同時嚴格守住化學正確與格式。把現有版本當「地板」——你要明顯做得比它更好，而不是持平。

## 角色設定聖經（這是你要推向的「目標」）

**分類帽（hat）**——
- 身份：閱歷極深的老靈魂，看過無數屆學生，對「不用心」零容忍。
- 語氣：**毒舌、嘴硬、反差萌**。表面刻薄挖苦，骨子裡是真心想教會你的老教授；刀子嘴、豆腐心。
- 說話特徵：短句、有節奏、擅長反諷；吐槽裡永遠夾著正確的知識點；學生答對時嘴硬不肯好好誇（例如「別誤會，我只是在核對事實」這種調調）。偶爾直呼學生名字 `{name}` 增加針對感。
- **界線（很重要）**：毒舌是「包裝」，內核是「希望你學會」。不要變成單純惡毒或人身攻擊；不要長篇說教；不要為了兇而犧牲笑點的節奏。刻薄要好笑、要有品味。

**魔法師（wiz）＝玩家化身**——緊張、老實、有點怕但肯學；是被吐槽的一方，會慢慢進步。台詞可以更有畫面、更有反應（吐槽回去、心虛、恍然大悟），但仍是「學生」的位置。

## 鐵律（違反就算失敗）

1. **化學事實一個字都不能改錯。** 每一段我都會列「必須守住的知識點」，改寫後那些辨識重點必須**原封不動地正確保留**（可以換句話說、換更生動的講法，但判斷方法和結論不能變、不能新增你不確定的化學）。
2. **只用台灣高中標準範圍的化學。** 不要加課本以外的反應或機制。
3. **格式不變**：每段仍是 `{ "who": "hat"或"wiz", "expr": "...", "text": "..." }` 的陣列。`{name}` 占位符保留（會在遊戲裡換成玩家名字）。
4. **輪數大致不變**：每一關維持大約現有的來回句數（8~9 句上下），不要暴增或砍半。
5. `expr` 只對 `hat` 有效，只能用這幾個值：`neutral / happy / sad / surprised / thinking / wink / annoyed`（省略視為 neutral）。`wiz` 行不用 expr。
6. **全部繁體中文（台灣用語）。** 化學符號正確：C=O、C≡C、–OH、–NH₂、–COOH、–CHO、C–O–C、C–X。

## 八段現有對話 ＋ 每段必須守住的知識點

### level1（碳氫骨架）
必守知識點：C–C 單鍵＝烷；有 C=C 雙鍵＝烯；有 C≡C 參鍵＝炔；六角形帶圈圈＝苯環＝芳香烴。
現有台詞：
- hat：「…又來了一個。{name}，是嗎。坐好，我很忙。」
- wiz：「呃……分類帽前輩好。這些全是碳和氫，看起來都一樣……」
- hat：「都一樣？說這話的人通常一題也看不對。仔細看：全是 C–C 單鍵的叫『烷』；躲了一根 C=C 雙鍵的叫『烯』；更硬派、有 C≡C 參鍵的叫『炔』。」
- wiz：「那那個六角形圈圈？」
- hat：「哦，你總算注意到了。那是苯環——『芳香烴』的印記。先把它刻進腦子裡，之後到處都是它。」
- wiz：「所以先找：有沒有雙鍵、參鍵、苯環？」
- hat：「……還算孺子可教。碳氫骨架是地基，地基看清楚，後面加官能基才不會一腳踩空。」
- wiz：「我記住了。烷、烯、炔、芳香。」
- hat：「少廢話。去做題——帽子不是用來聊天的。」

### level2（單鍵氧家族：醇/醚）
必守知識點：–O–H（氧接碳又接氫）＝醇（例：乙醇＝酒精）；C–O–C（氧夾在兩碳中間、沒有 H）＝醚；醇與醚的差別就是「氧上有沒有掛 H」。
現有台詞：
- hat：「骨架過關了。現在加一個氧進來——但氧很挑剔，接法不同、名字就不同。」
- wiz：「氧怎麼接？」
- hat：「氧如果一手抓碳、一手抓氫，–O–H，那叫『醇』。乙醇，就是你們喝的那個。」
- wiz：「那如果兩手都抓碳呢？」
- hat：「C–O–C，氧夾在兩個碳中間，那叫『醚』。看起來差一個 H，性質差了十萬八千里。」
- wiz：「所以關鍵就是那個 H 有沒有？」
- hat：「就那一個 H。{name}，你別看這題簡單，每年都有人把乙醇和乙醚看成同一家人。」
- wiz：「……我不會的。先找 –OH。」
- hat：「說得比唱得好聽。去證明吧。」

### level3（雙鍵氧家族：醛/酮）
必守知識點：C=O＝羰基；羰基在碳鏈末端、旁邊接一個 H（–CHO）＝醛；羰基夾在兩個碳中間、沒有 H＝酮（例：丙酮＝去光水）。位置決定醛或酮。
現有台詞：
- hat：「這一關，氧升級了——它跟碳之間是『雙鍵』，C=O，叫羰基。記住這個名字。」
- wiz：「羰基……醛跟酮有什麼差？」
- hat：「差在位置。羰基如果長在碳鏈末端，旁邊還黏著一個 H，那是『醛』，–CHO。」
- wiz：「那酮？」
- hat：「羰基被夾在兩個碳中間，沒有那個 H，那是『酮』。丙酮你應該聽過，去光指甲油用的。」
- wiz：「所以 C=O 在邊邊是醛、在中間是酮。」
- hat：「正確。雖然是從你嘴裡說出來的，讓我有點不習慣。」
- wiz：「……謝謝誇獎（吧？）」
- hat：「別誤會，我只是在核對事實。去做題，{name}。」

### level4（雙氧複合：羧酸/酯）
必守知識點：同一個碳上同時有 C=O 和 –OH（–COOH）＝羧酸（例：乙酸＝醋）；把羧酸 –OH 的 H 換成碳（C(=O)–O–C）＝酯（例：水果香）；差別在尾巴是 –O–H 還是 –O–碳。
現有台詞：
- hat：「好，這關開始難了。同一個碳上，同時掛兩種氧。準備好了嗎？」
- wiz：「……說實話沒有。」
- hat：「誠實。算你一點。C=O 加 –OH 黏在同一個碳上，那叫『羧酸』，–COOH。乙酸，就是醋。」
- wiz：「那酯呢？看起來也有兩個氧。」
- hat：「把羧酸的 –OH 裡那個 H 換成碳，就成了酯：C(=O)–O–C。水果香大多是酯，醋酸是羧酸——聞到不同，結構就差那個位置。」
- wiz：「差別只在尾巴是 –O–H 還是 –O–碳。」
- hat：「對。你這關如果還混淆，我建議你去聞一下醋，印象會比較深刻。」
- wiz：「……我會看清楚的。」
- hat：「最好是。酸與酯，出發。」

### level5（雜原子與鹵素：胺/鹵化物）
必守知識點：氮接碳、可能還接氫（–NH₂/–NHR/–NR₂）、旁邊沒有 C=O＝胺；小心 –NH₂ 和 –OH 長得有點像別看錯；碳接 F/Cl/Br/I（C–X）＝有機鹵化物。
現有台詞：
- hat：「前面都是碳氫氧在玩。這一關，請兩個新角色上場：氮，還有鹵素。」
- wiz：「胺是 –NH₂ 那個嗎？」
- hat：「對，氮接著碳還黏著氫，–NH₂，那是『胺』。小心——–NH₂ 跟 –OH 長得有那麼一點點像，別看錯。」
- wiz：「那鹵素呢？F、Cl、Br、I……」
- hat：「碳上接了這四個其中一個，C–X，就是『鹵化物』。沒有特別難，就是認符號。」
- wiz：「看到 N 想胺、看到 X 想鹵化物。」
- hat：「可以。雖然真正的分子常常一身好幾個官能基，到那時候你要學會看誰是主角。但那是以後的事。」
- wiz：「一步一步來。先把 N 跟 X 認熟。」
- hat：「難得你知道不要貪多。去吧，{name}。」

### level6（綜合複習＋酚）
必守知識點：level1~5 全混；**酚自成一類**——–OH「直接」接在苯環碳上＝酚；苯甲醇的 –OH 接在苯環外的 –CH₂– 上＝醇（不是酚）；苯甲醛=醛、苯甲酸=羧酸、苯胺=胺；苯環只是附件，主角是官能基。
現有台詞：
- hat：「烷烯炔芳香、醇醚、醛酮、羧酸酯、胺鹵化物——都見過了。這關全混在一起。」
- wiz：「全混……而且你剛才提到苯酚是單獨一類？」
- hat：「–OH 直接接在苯環的碳上，那是『酚』，自成一類。別以為接了苯環的 –OH 還算醇，那是偷懶的想法。」
- wiz：「所以苯甲醇是醇，苯酚才是酚。」
- hat：「正確。苯甲醇的 –OH 是接在苯環外面的 –CH₂– 上；苯酚的 –OH 直接接在環上。差這一截，類別就不同。」
- wiz：「那苯甲醛、苯甲酸、苯胺呢？」
- hat：「醛、羧酸、胺。苯環只是附件，主角還是官能基。{name}，冷靜看、一個一個找，不要被苯環嚇到。」
- wiz：「好。一個一個找，不要被外型騙了。」
- hat：「這才像話。終極分類——如果你在這關還搞錯，我會假裝不認識你。去吧。」

### levelShell（苯環陷阱關「龜殼與它的產地」）
必守知識點：整關都有苯環（暱稱「龜殼」）；看到苯環別急著選酚；–OH「直接」接環＝酚、接在環伸出的尾巴（–CH₂–OH）＝醇；苯甲醛=醛、苯甲酸=羧酸、苯乙酮=酮、苯甲醚=醚、氯苯=鹵化物、苯胺=胺；只有整顆是苯環＋烷基（甲苯/二甲苯）才選芳香烴；「把苯環遮起來，剩下那塊才是答案」。
現有台詞：
- hat：「{name}，這一關全是『龜殼』——那個畫成六角形帶圈圈的，叫苯環。新手看到龜殼就喊『酚』，每年都有人這樣丟分。」
- wiz：「不是嗎？我看它們都有苯環，有些還掛著 –OH……」
- hat：「看清楚 –OH 的落腳點。直接黏在龜殼的碳上，那才叫『酚』；接在龜殼伸出來的尾巴上——比如苯甲醇的 –CH₂–OH——那只是個普通的『醇』。」
- wiz：「所以苯酚是酚、苯甲醇是醇。那苯甲醛、苯甲酸呢？」
- hat：「醛、羧酸。苯環只是背景，主角永遠是它身上掛的官能基。苯甲醛末端一個 –CHO，苯甲酸一個 –COOH，差一個位置，類別就不同。」
- wiz：「苯乙酮、苯甲醚、氯苯、苯胺……也都是看官能基決定？」
- hat：「酮、醚、鹵化物、胺。對。把龜殼遮起來，剩下那一小塊才是答案。」
- wiz：「懂了。先把苯環當背景，再看它身上掛了什麼。」
- hat：「難得開竅。去吧，{name}——別讓這些龜殼把你搞糊塗了。」

### level99（資優全英挑戰）
必守知識點：這關選項是英文類別名；提醒 Alkane/Alkene/Alkyne 只差一個字母易混；Carboxylic Acid（–COOH）vs Ester（–COO–C）差在 H 換成碳鏈；Phenol＝–OH 直接接苯環，benzyl alcohol（–CH₂–OH）是 Alcohol。此關對白可中英夾雜（符合「全英挑戰」情境）。
現有台詞：
- hat：「……你又來了。{name}，你知道這關選項全是英文嗎？」
- wiz：「知道。我準備好了。」
- hat：「嘴上說準備好，手不一定跟得上。Alkane、Alkene、Alkyne——光這三個就有人傻傻分不清楚。」
- wiz：「Alcohol、Ether、Aldehyde、Ketone……我背過了。」
- hat：「『背過』跟『看到結構式就知道』是兩件事。Carboxylic Acid 和 Ester 差在哪？用英文回答我。」
- wiz：「……Carboxylic Acid 有 –COOH，Ester 有 –COO–C，差在那個 H 換成 carbon chain。」
- hat：「……還行。Phenol 呢？」
- wiz：「–OH directly bonded to the aromatic ring carbon. Not –CH₂–OH，那是 benzyl alcohol，是 Alcohol。」
- hat：「好。你比我預期的強一點點——就一點點，別驕傲。Amine 跟 Halide 別看錯，Go on, {name}.」

```json
}
```
