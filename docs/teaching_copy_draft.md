## A. 判斷流程（決策樹）— 核心！看到結構照這個順序問

> 放在「新手導覽」與 level6 綜合關；也是所有 whyHints／tutorial 背後的統一邏輯。

**分類帽的判斷流程**
看到一個結構，照這個順序問自己：

1. 只有碳（C）和氫（H）嗎？
　· 碳碳全是單鍵 → **烷**
　· 有 C=C 雙鍵 → **烯**
　· 有 C≡C 參鍵 → **炔**
　· 有苯環（六角形帶圈圈）、環上只接碳氫 → **芳香烴**

2. 有鹵素嗎？（碳接 F、Cl、Br、I，如 C–Cl）→ **有機鹵化物**

3. 有氮嗎？（碳接氮、旁邊沒有 C=O，如 –NH₂）→ **胺**

4. 有氧嗎？先看氧和碳之間是單鍵還是雙鍵：
　· **單鍵氧**：
　　- O–H 直接接苯環 → **酚**
　　- O–H 接一般的碳 → **醇**
　　- 氧夾在兩碳中間（C–O–C）→ **醚**
　· **雙鍵氧（C=O，羰基）**：
　　- 同一個碳上還有 O–H（–COOH）→ **羧酸**
　　- 羰基接 –O–碳（C(=O)–O–C）→ **酯**
　　- 羰基在末端、接一個 H（–CHO）→ **醛**
　　- 羰基夾在兩碳中間 → **酮**

> 這張流程也是「為什麼答錯」提示的骨架——每一類的提示，就是在講「你在決策樹的哪一步走錯了」。

## B. whyHints — 練習模式「答錯」時，分類帽點破的一句話

| 類別 | 辨識重點（正向：有…就是它） | 常見陷阱 |
|---|---|---|
| **烷 Alkane** | 整個分子只有碳和氫，而且碳與碳之間全是單鍵（一條線）。乾乾淨淨、沒有多出來的官能基，就是烷。 | 碳碳之間出現兩條線是烯、三條線是炔；烷全是單鍵。 |
| **烯 Alkene** | 碳與碳之間有一條雙鍵（兩條平行線 C=C），這條 C=C 就是烯的記號。 | 兩條線是烯、三條線是炔，數清楚；六角形帶圈圈的苯環另屬芳香烴。 |
| **炔 Alkyne** | 碳與碳之間有一條參鍵（三條線 C≡C），這條 C≡C 就是炔的記號。 | 三條線是炔、兩條線是烯，別把線數看錯。 |
| **醇 Alcohol** | 有一個羥基（O–H：氧一邊接碳、一邊接氫），而且這個 O–H 長在一般的碳鏈上，就是醇。 | **和醛最容易混：醇的 H 掛在「氧」上（O–H）、氧碳之間是單鍵；醛的 H 掛在「碳」上、碳氧之間是雙鍵（C=O）。** 另外：氧兩邊都接碳是醚；O–H 直接接苯環是酚。 |
| **醚 Ether** | 氧的兩邊都接碳（C–O–C），這個「碳–氧–碳」就是醚。 | 看氧上有沒有掛氫：有 O–H 是醇，被兩個碳夾住、沒有 H 是醚。 |
| **醛 Aldehyde** | 有一個羰基（C=O）長在碳鏈末端、羰基碳上還接著一個氫（合寫成 –CHO），就是醛。 | **和醇別混：醛有碳氧雙鍵（C=O）、H 在碳上；醇沒有 C=O、H 在氧上（O–H）。** 和酮的差別：醛的羰基在末端接 H、酮的夾在兩碳中間。 |
| **酮 Ketone** | 有一個羰基（C=O）被兩個碳夾在中間（兩邊都接碳），就是酮。 | 夾在中間是酮、在末端接 H 是醛。 |
| **羧酸 Carboxylic Acid** | 同一個碳上同時有羰基（C=O）和羥基（O–H），合寫成 –COOH（羧基），就是羧酸。 | 尾巴接氫（O–H）是羧酸；那個 H 換成碳（–O–碳）就是酯。 |
| **酯 Ester** | 有一段 C(=O)–O–C（羰基碳先接一個氧、那個氧再接碳），就是酯。 | 尾巴接碳是酯、接氫（O–H）是羧酸；酯有 C=O、醚沒有。 |
| **胺 Amine** | 有一個氮（N）接在碳上，而且氮旁邊沒有羰基（C=O），就是胺。最常見的長相是 –NH₂（氨基）。 | –NH₂ 和 O–H 畫起來有點像，看清楚中間那個原子是 N 還是 O。 |
| **芳香烴 Aromatic Hydrocarbon** | 有苯環（六角形帶圈圈），而且苯環上只接碳氫基（甲基、乙基等）、整顆乾乾淨淨，就是芳香烴（例：苯、甲苯、二甲苯）。 | 苯環上若掛了官能基就選那個官能基，不是芳香烴——苯環常只是背景。（如：–O–H 羥基→酚、–CHO 醛基→醛、–COOH 羧基→羧酸、–NH₂ 氨基→胺、鹵素→鹵化物） |
| **有機鹵化物 Halide** | 有一個碳接著鹵素，例如 C–F、C–Cl、C–Br、C–I（統稱 C–X，X＝F、Cl、Br、I 這些鹵素），就是有機鹵化物。 | 留意角落的鹵素符號別看漏。 |
| **酚 Phenol** | 有一個 O–H 直接接在苯環的碳上，就是酚。 | O–H 直接接環是酚；接在環外伸出的碳（如苯甲醇的 –CH₂–O–H）是醇。 |

## C. levelTutorials — 每關進關前的教學頁（配結構圖，圖上會標示官能基）

> 頁內 1. 2. 3. 與換行在遊戲裡是純文字呈現。多個官能基一律「換行＋中文名」。

### level1｜碳氫骨架（烷／烯／炔／芳香）

**頁1・數碳和碳之間的線**
這一關的分子只有碳（C）和氫（H）。判斷第一步：看碳和碳之間有幾條線。
1. 一條線（單鍵 C–C）→ 烷（例：瓦斯的甲烷、丙烷，最安定）
2. 兩條線（雙鍵 C=C）→ 烯
3. 三條線（參鍵 C≡C）→ 炔
看被標示的那條鍵，數清楚幾條線就不會錯。

**頁2・六角形加圈圈：苯環**
看到「六角形、裡面還有一個圈圈」的結構，那叫苯環，屬於芳香烴。先把這個記號記起來：六角形＋圈圈＝苯環，後面關卡它到處都會出現。

### level2｜單鍵氧家族（醇／醚）

**頁1・氧登場了**
從這一關開始，分子裡多了氧（O）。同樣一個氧，接法不同、名字就不同——這一關學會分辨氧的兩種接法。

**頁2・氧的兩種接法**
1. 氧一邊接碳、一邊接氫（O–H，這個 O–H 叫「羥基」）→ 醇（例：乙醇＝酒精）
2. 氧的兩邊都接碳（C–O–C）→ 醚
一句話分辨：看被標示的那個氧，上面有掛氫（H）的是醇，被兩個碳夾住的是醚。

### level3｜雙鍵氧家族（醛／酮）

**頁1・碳氧雙鍵叫羰基**
這一關的氧和碳之間是雙鍵（C=O），這個 C=O 的正式名字叫「羰基」，先記住它。接下來要看的是：羰基長在分子的哪個位置。

**頁2・看羰基住在哪**
1. 羰基在碳鏈末端、旁邊還接一個氫（合寫成 –CHO）→ 醛
2. 羰基被兩個碳夾在中間、沒有那個氫 → 酮（例：丙酮＝去光水）
看被標示的羰基在末端還是中間，就能分辨。

**頁3・別把醛和醇搞混**
醛（–CHO）和醇（O–H）名字像、都有氧，但關鍵不同：
1. 醇：H 掛在「氧」上（O–H），氧和碳之間是單鍵
2. 醛：H 掛在「碳」上（C–H），碳和氧之間是雙鍵（C=O 羰基）
看那個氧是單鍵還是雙鍵，就分得開。

### level4｜雙氧複合（羧酸／酯）

**頁1・同一個碳上兩種氧：羧酸**
這一關難一點。如果同一個碳上同時有羰基（C=O）和羥基（O–H），合寫成 –COOH（叫「羧基」），那就是羧酸。看被標示的 –COOH——醋的酸味來源（乙酸）就是羧酸。

**頁2・羧酸和酯差在尾巴**
把羧酸 –COOH 尾巴的那個氫換成一段碳，就變成酯。判斷看尾巴：
1. 尾巴接氫（O–H）→ 羧酸
2. 尾巴接碳（–O–碳，即 C(=O)–O–C）→ 酯（例：水果香、香蕉油）

### level5｜雜原子與鹵素（胺／鹵化物）

**頁1・兩個新原子上場**
前面都在玩碳、氫、氧，這一關換氮（N）和鹵素上場。看碳接上了誰：
1. 碳接氮（最常見是 –NH₂，叫「氨基」）→ 胺（小提醒：–NH₂ 和 O–H 畫起來有點像，看清楚中間是 N 還是 O）
2. 碳接鹵素（C–F、C–Cl、C–Br、C–I，統稱 C–X）→ 有機鹵化物
一句話：看到 N 想胺、看到 F/Cl/Br/I 想鹵化物。

### level6｜綜合複習＋酚

**頁1・用「判斷流程」一步步走**
前面學的（烷烯炔芳香、醇醚、醛酮、羧酸酯、胺鹵化物）這一關會混在一起。沒有捷徑，照判斷流程走：
1. 只有碳氫嗎？（看鍵數、有沒有苯環）
2. 有鹵素嗎？
3. 有氮嗎？
4. 有氧嗎？氧是單鍵（醇/酚/醚）還是雙鍵 C=O（醛/酮/羧酸/酯）？

**頁2・新角色：酚（別跟醇混）**
「酚」自成一類：O–H「直接」接在苯環的碳上才叫酚（苯酚就是它）。如果 O–H 接在苯環外面伸出來的碳上（像苯甲醇的 –CH₂–O–H），那是普通的「醇」。差這一小截，類別就不同。

### levelShell｜苯環陷阱（龜殼與它的產地）

**頁1・這關全是苯環**
這一關每個分子都帶著六角形帶圈圈的苯環。新手最常犯的錯：看到苯環就喊「酚」。先深呼吸——苯環常常只是背景，不是答案。

**頁2・看 O–H 的落腳點**
1. O–H 直接黏在苯環的碳上 → 酚
2. O–H 接在苯環伸出來的尾巴上（像苯甲醇的 –CH₂–O–H）→ 醇
同樣有苯環、同樣有 O–H，落腳點不同，答案就不同。

**頁3・把苯環遮起來看**
訣竅是「把苯環遮起來，剩下那一小塊官能基才是答案」：
苯甲醛→醛、苯甲酸→羧酸、苯乙酮→酮、苯甲醚→醚、氯苯→鹵化物、苯胺→胺。
只有整顆就是苯環＋烷基（像甲苯、二甲苯）才選「芳香烴」。

### level99｜資優全英挑戰

**頁1・這關答案是英文**
玩法和前面一樣（看結構式選類別），只是選項全換成英文官能基名稱。結構怎麼看、判斷流程都沒變，你只要把腦中的中文名換成英文名。

**頁2・13 類中英對照**
烷 Alkane／烯 Alkene／炔 Alkyne／醇 Alcohol／醚 Ether／醛 Aldehyde／酮 Ketone／羧酸 Carboxylic Acid／酯 Ester／胺 Amine／芳香烴 Aromatic Hydrocarbon／鹵化物 Halide／酚 Phenol。
最容易看錯的兩組：
1. Alkane／Alkene／Alkyne——只差一個字母
2. Carboxylic Acid／Ester——差在那個 H 被換成碳鏈
