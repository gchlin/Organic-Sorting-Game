## A. whyHints — 練習模式「答錯」時，分類帽點破的一句話

| 類別 | 辨識重點（答錯時顯示） | 常見陷阱 |
|---|---|---|
| **烷 Alkane** | 整個分子只有碳和氫，碳與碳之間都是單鍵（一條線），沒有雙鍵、參鍵，也沒有氧／氮／鹵素。看不到任何額外官能基，就是烷。 | 跟烯／炔混：碳碳之間出現兩條線（雙鍵）是烯、三條線（參鍵）是炔；單鍵才是烷。 |
| **烯 Alkene** | 碳與碳之間出現一條「雙鍵」（兩條平行線 C=C），這個 C=C 就是烯的官能基。 | 別跟炔混（兩條線是烯、三條線是炔）；也別把苯環當烯——苯環雖有雙鍵，但整顆六角形帶圈圈是芳香烴。 |
| **炔 Alkyne** | 碳與碳之間是「參鍵」（三條線 C≡C），這個 C≡C 就是炔的官能基。 | 跟烯混：三條線（參鍵）才是炔，兩條線（雙鍵）是烯。數清楚線的數量。 |
| **醇 Alcohol** | 有一個「羥基」：氧一邊接碳、一邊接氫（–O–H），而且這個 –OH 接在一般的碳上（不是苯環、也不是接著 C=O 的碳）。 | 跟醚混：氧兩邊都接碳、沒有 H 是醚。跟酚混：–OH 直接接在苯環上是酚。跟羧酸混：同一碳上若還有 C=O 就是羧酸。 |
| **醚 Ether** | 氧的兩邊「都」接碳（C–O–C），氧上面沒有掛氫。 | 跟醇混：關鍵看氧上有沒有 H——有 H（–O–H）是醇，被兩個碳夾著、沒 H 是醚。 |
| **醛 Aldehyde** | 有一個「羰基」（碳氧雙鍵 C=O），且長在碳鏈「末端」、羰基碳上還接一個氫（–CHO）。 | 跟酮混：羰基在末端接 H 是醛、被兩個碳夾在中間是酮。位置是關鍵。 |
| **酮 Ketone** | 有一個羰基（C=O），且被「兩個碳」夾在中間（兩邊都是碳、沒接氫）。 | 跟醛混：夾中間是酮、末端接 H 是醛。若羰基旁還接 –OH 或 –O–碳，就不是單純的酮（是羧酸／酯）。 |
| **羧酸 Carboxylic Acid** | 同一個碳上「同時」有羰基（C=O）和羥基（–OH），合寫成 –COOH（羧基），通常在末端。 | 跟酯混：尾巴接氫（–O–H）是羧酸；那個 H 若被換成碳（–O–碳）就是酯。 |
| **酯 Ester** | 像羧酸 –COOH，但 –OH 上的氫被換成碳，變成 C(=O)–O–C（羰基碳先接氧、氧再接碳）。 | 跟羧酸混：尾巴接氫是羧酸、接碳是酯。跟醚混：酯有 C=O，醚沒有。 |
| **胺 Amine** | 有一個氮接在碳上（–NH₂／–NHR／–NR₂），且氮旁邊「沒有」羰基（C=O）。 | 跟醇混：–NH₂ 和 –OH 畫起來有點像，看清楚中間那個原子是 N 還是 O。 |
| **芳香烴 Aromatic Hydrocarbon** | 含苯環（六角形帶圈圈），且苯環上「只」接碳氫基（甲基、乙基等），沒有其他官能基（例：苯、甲苯、二甲苯）。 | 苯環上只要掛了 –OH／–CHO／–COOH／–NH₂／鹵素等，就要選那個官能基，不是芳香烴——苯環常只是背景。 |
| **有機鹵化物 Halide** | 有一個碳接著鹵素（F、Cl、Br、I 之一），即 C–X。看到這四個鹵素符號接在碳上就是。 | 通常好認，但別漏看角落的鹵素符號；本遊戲單官能基情境下，看到 C–X 就選鹵化物。 |
| **酚 Phenol** | 有一個 –OH（羥基），且「直接」接在苯環的碳上。直接長在苯環上的 –OH 才是酚。 | 跟醇混（最重要）：–OH 若接在苯環外伸出的碳上（如苯甲醇 –CH₂–OH）是醇，不是酚。差在是不是「直接」黏在環上。 |

## B. levelTutorials — 每關進關前的教學頁（配該官能基的結構圖，圖上會標示）

### level1｜碳氫骨架（烷／烯／炔／芳香）

1. **先看碳和碳怎麼連** — 這一關的分子只有碳（C）和氫（H）兩種原子。判斷第一步，是盯著「碳和碳之間」的連線；連線的數量，決定它是哪一類。
2. **單鍵是烷** — 碳和碳之間若每一段都只有「一條線」（單鍵 C–C），而且整個分子沒有別的花樣，那就是「烷」。看被標示的單鍵骨架——家裡的瓦斯（甲烷、丙烷）就是烷，最安定、最不愛反應。
3. **兩條線烯、三條線炔** — 碳碳之間出現「兩條線」，那條 C=C 叫「雙鍵」，分子是「烯」；出現「三條線」，那條 C≡C 叫「參鍵」，是「炔」。看被標示的那條鍵，數清楚幾條線就不會錯。
4. **六角形加圈圈：苯環** — 看到「六角形、裡面一個圈圈」的結構，那叫「苯環」，屬於「芳香烴」。先記住：六角形＋圈圈＝苯環；它在後面關卡到處會出現。

### level2｜單鍵氧家族（醇／醚）

1. **氧登場了** — 從這一關開始，分子裡多了「氧（O）」。同樣一個氧，接法不同、名字就完全不同——這一關學會分辨氧的兩種接法。
2. **氧接碳又接氫：醇** — 氧一邊接碳、一邊接一個氫（–O–H），這個 –O–H 叫「羥基」；羥基接在一般碳鏈上就是「醇」。看被標示的 –OH——你們喝的酒、消毒的酒精，主角都是乙醇。
3. **氧被兩碳夾住：醚** — 氧的兩邊「都」接碳（C–O–C）、上面沒有氫，那就是「醚」。醚和醇只差一個 H，判斷就一句話：氧上有沒有掛 H——有 H 是醇、被兩碳夾著是醚。

### level3｜雙鍵氧家族（醛／酮）

1. **碳氧雙鍵叫羰基** — 這一關的氧和碳之間是「雙鍵」（C=O），這個 C=O 正式名字叫「羰基」，先記住它。接下來要看：羰基長在分子的哪個位置。
2. **末端是醛、中間是酮** — 羰基長在碳鏈「末端」、旁邊還接一個氫（–CHO）是「醛」；羰基被「兩個碳夾在中間」、沒那個氫是「酮」。看被標示的羰基在哪——丙酮（去光水主成分）就是最有名的酮。

### level4｜雙氧複合（羧酸／酯）

1. **同一碳上兩種氧：羧酸** — 這一關難一點：同一個碳上「同時」有羰基（C=O）和羥基（–OH），合寫成 –COOH（叫「羧基」），那就是「羧酸」。看被標示的 –COOH——醋的酸味來源（乙酸）就是羧酸。
2. **把H換成碳：酯** — 把羧酸 –COOH 裡那個氫換成一段碳（變成 C(=O)–O–C），就是「酯」。判斷關鍵在尾巴：接氫（–O–H）是羧酸、接碳（–O–碳）是酯。很多水果香、香蕉油都是酯。

### level5｜雜原子與鹵素（胺／鹵化物）

1. **看到氮：胺** — 前面都在玩碳氫氧，這一關換「氮（N）」上場。碳上接著氮、氮上可能還接氫（–NH₂／–NHR／–NR₂），且氮旁邊「沒有」羰基，這就是「胺」。小提醒：–NH₂ 和 –OH 畫起來有點像，看清楚中間是 N 還是 O。
2. **看到F/Cl/Br/I：鹵化物** — 碳上接了氟、氯、溴、碘其中一個（C–X），就是「有機鹵化物」。這類不難，就是認得那幾個鹵素符號。一句話：看到 N 想胺、看到 F/Cl/Br/I 想鹵化物。

### level6｜綜合複習＋酚

1. **這關全部混在一起** — 烷烯炔芳香、醇醚、醛酮、羧酸酯、胺鹵化物——前面學的通通會出現。沒有捷徑，一個一個看：先找苯環，再看有沒有羰基（C=O）、在末端還是中間，再看 –OH 接在哪，最後看有沒有氮、鹵素。
2. **新角色：酚（別跟醇混）** — 「酚」自成一類：–OH「直接」接在苯環的碳上才叫酚（苯酚就是它）。若 –OH 接在苯環外伸出的碳上（像苯甲醇 –CH₂–OH），那只是普通的「醇」。差這一小截，類別就不同。

### levelShell｜苯環陷阱（龜殼與它的產地）

1. **這關全是苯環** — 這一關每個分子都帶著六角形帶圈圈的「苯環」。新手最常犯的錯：看到苯環就喊「酚」。先深呼吸——苯環常常只是背景，不是答案。
2. **看–OH的落腳點** — 若分子有 –OH：直接黏在苯環的碳上才是「酚」；接在苯環伸出的尾巴上（像苯甲醇 –CH₂–OH）只是「醇」。同樣有苯環、同樣有 –OH，落腳點不同，答案就不同。
3. **把苯環遮起來看** — 苯甲醛是醛、苯甲酸是羧酸、苯乙酮是酮、苯甲醚是醚、氯苯是鹵化物、苯胺是胺——訣竅是「把苯環遮起來，剩下那一小塊官能基才是答案」。只有整顆就是苯環＋烷基（甲苯、二甲苯）才選「芳香烴」。

### level99｜資優全英挑戰

1. **這關答案是英文** — 玩法和前面一樣（看結構式選類別），只是選項全換成英文官能基名稱。結構怎麼看、判斷流程都沒變，你只要把腦中的中文名換成英文名。
2. **13類中英對照** — 烷 Alkane／烯 Alkene／炔 Alkyne／醇 Alcohol／醚 Ether／醛 Aldehyde／酮 Ketone／羧酸 Carboxylic Acid／酯 Ester／胺 Amine／芳香烴 Aromatic Hydrocarbon／鹵化物 Halide／酚 Phenol。最容易看錯的：Alkane／Alkene／Alkyne 只差一個字母；Carboxylic Acid 和 Ester 差在那個 H 被換成碳鏈。
