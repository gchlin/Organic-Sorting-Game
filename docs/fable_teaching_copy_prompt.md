# Fable 教學文案 Prompt（貼到另一個 Fable 5 視窗用）

> 用法：把下面「=== PROMPT 開始 ===」到「=== PROMPT 結束 ===」之間**整段**複製，貼進一個新的 Fable 5 對話。它會回一份 JSON，把那份 JSON 貼回給 Opus，我來接進程式。

=== PROMPT 開始 ===

你是一位很會把難懂的化學講到「零基礎學生也聽得懂」的高中老師兼遊戲文案。

我在做一款高中有機化學遊戲《有機分類帽》：畫面給一個分子的**結構式**，學生要把它分到 13 個「官能基」類別。**很多玩家從來沒學過有機化學**，看到「羰基」「羥基」「sp³ 碳」這種詞會直接放棄。你的任務是幫我寫兩批教學文案。

## 最重要的寫作原則（每一句都要守住）

**核心：專有名詞是「教學目標」，不是要避開的東西。** 這款遊戲的目的，就是讓學生學會「羥基、羰基、醛、酮、酯…」這些正式名詞。所以不要為了「親切」而用綽號取代正式名稱、或迴避術語。真正的「零基礎友善」是——**把正式名詞好好地教會他**，而不是不教。

1. **每個正式名詞都要出現、並用一句精確的話定義，之後持續使用它。** 例：「碳和氧之間是一條雙鍵（C=O），這個 C=O 就叫『羰基』。」——名詞是終點，學生看完要記得的是「羰基」這個詞，不是綽號。
2. **可以從「結構上看得到什麼」切入再帶出名詞，但描述必須化學正確。** 不要用會製造錯誤概念的比喻。
3. **比喻只能當「橋」，不能取代事實，而且必須經得起對照結構。**
   - 可以：「氧的一邊接碳、另一邊接一個氫（–O–H）」——這是對結構的準確描述。
   - 不可以：「氧很貪心、喜歡搶電子」這類擬人化——會讓學生建立錯誤模型，日後更難糾正。
   - 任何比喻都要能直接對回結構式上真實的鍵結；只要你不確定它會不會誤導，就改用平實、準確的講法。
4. **生活例子用來「幫記憶」，不是用來「講原理」。** 乙醇＝酒精、丙酮＝去光水、乙酸＝醋、酯＝水果香、甲烷丙烷＝瓦斯——這些可以放，但別讓生活例子取代「怎麼從結構判斷類別」；判斷方法要講清楚、要精確。
5. **口吻清楚、有耐心，像對一個聽不懂而有點挫折的學生講話——但「清楚」不等於「幼稚」。** 不要過度俏皮或撒嬌而犧牲準確度。
6. **全部繁體中文（台灣用語）。**
7. **只用台灣高中標準範圍內的內容。** 不確定某個說法是否屬於高中程度，就**不要寫、不要自己編**——寧可簡單也不要超綱或講錯。
8. 化學符號正確：雙鍵 C=O、參鍵 C≡C、–OH、–NH₂、–COOH、–CHO、C–O–C、C–X（X=F/Cl/Br/I）。

## 交付 A：whyHints（練習模式「答錯」時，分類帽講一句話點醒學生）

學生答錯的當下會看到這一句，所以要**短、準、點破關鍵**。對下面 13 類，每一類給我：
- `辨識重點`：一句話「你怎麼從結構式一眼看出它是這一類」（把我給的「草稿」改寫成零基礎友善版）。
- `常見陷阱`：最容易跟它搞混的是哪一類、怎麼用一句話區分（如果這類沒有明顯陷阱，填空字串 `""`）。

13 類與辨識重點草稿：
1. 烷 Alkane — 只有 C–C 單鍵和 C–H，沒有任何含氧/氮/鹵的官能基
2. 烯 Alkene — 含 C=C 雙鍵
3. 炔 Alkyne — 含 C≡C 參鍵
4. 醇 Alcohol — –OH 接在一般（飽和）碳上
5. 醚 Ether — C–O–C，氧夾在兩個碳之間（沒有 OH、也沒有 C=O）
6. 醛 Aldehyde — –CHO：C=O 在碳鏈末端，旁邊接一個 H
7. 酮 Ketone — C=O 夾在兩個碳之間
8. 羧酸 Carboxylic Acid — –COOH：同一個碳上同時有 C=O 和 –OH
9. 酯 Ester — –COO–：像羧酸但 –OH 的 H 被換成碳（C(=O)–O–C）
10. 胺 Amine — 含 –NH₂ / –NHR / –NR₂（氮接碳，旁邊沒有 C=O）
11. 芳香烴 Aromatic Hydrocarbon — 含苯環，且苯環上只接碳氫基（沒有其他官能基）
12. 鹵化物 Halide — 含 C–X（X＝F、Cl、Br、I）
13. 酚 Phenol — –OH 直接接在苯環的碳上（若接在 –CH₂– 之類的碳上就算醇，不是酚）

## 交付 B：levelTutorials（每一關開始前，分類帽放 2–4 頁教學）

每頁格式：`{ "標題": "5~10字", "內文": "2~4句、可以直接對學生說話的口吻" }`。
每一關建議涵蓋：①這關的官能基長什麼樣（描述結構特徵）→ ②怎麼一眼認出它 → ③最容易搞錯的地方 → ④生活例子/為什麼要學。頁數 2–4 之間你決定。

**（重要）教學頁旁邊會有結構圖，且遊戲會把「正在講解的那個官能基」在結構圖上『標示/塗色』出來。** 所以你的文字可以直接請學生「看被標示（塗色）出來的那一段」，重點放在「那一段為什麼是這個官能基」；**不必**用文字去描述它在圖的左邊還是右邊、上面還是下面（那個交給圖）。

各關主題：
- `level1` 碳氫骨架：烷、烯、炔、芳香烴（苯環）→ 建議 3~4 頁
- `level2` 單鍵氧家族：醇、醚 → 2~3 頁
- `level3` 雙鍵氧家族（羰基）：醛、酮 → 2 頁
- `level4` 雙氧複合：羧酸、酯 → 2 頁
- `level5` 雜原子與鹵素：胺、有機鹵化物 → 2 頁
- `level6` 綜合複習（level1~5 全混）＋特別強調：**酚自成一類**（–OH 直接接苯環才是酚；苯甲醇的 –OH 接在苯環外的 CH₂ 上，是醇不是酚）→ 2 頁
- `levelShell` 苯環陷阱專練：看到苯環（六角形帶圈圈）不要急著選「酚」，先看苯環上接的是什麼官能基、–OH 是不是「直接」接在環上（苯酚=酚、苯甲醇=醇、苯甲醛=醛、苯甲酸=羧酸、苯胺=胺、甲苯/二甲苯=芳香烴、氯苯=鹵化物、苯乙酮=酮、苯甲醚=醚）→ 3 頁

### 語氣與品質標竿（照這個水準寫，這是遊戲現有、可接受的範例）

> 標題：「氧一手牽碳、一手抓氫：醇」
> 內文：「這一關開始有『氧（O）』登場。第一種接法：氧的一邊接碳、另一邊接一個氫（寫成 –O–H，叫『羥基』）。只要這個 –OH 接在普通的碳鏈上，就是『醇』。你們喝的酒、消毒用的酒精，主角都是乙醇。」

> 標題：「氧被兩個碳夾在中間：醚」
> 內文：「第二種接法：氧的兩邊『都』接碳（C–O–C），中間沒有那個 H。這叫『醚』。醚跟醇看起來只差一個 H，性質卻差很多——所以辨識重點就是：氧上面『有沒有掛 H』。有 H 是醇、夾在兩碳中間沒 H 是醚。」

（注意：這是「教學頁」，語氣要清楚好懂、**不用刻意毒舌**。毒舌是另外的劇情對話，不在這次範圍。）
