# 示性式審核表（草稿，待化學老師校訂）

> **用途**：《有機分類魔導書》要新增「示性式挑戰」關卡——題面不看結構圖，改看**示性式**（如 CH₃COOH），學生一樣判官能基分類。
> 遊戲資料庫目前**沒有示性式**，只有結構圖與 SMILES。這份表是我（AI）依 SMILES＋課本慣例草擬的示性式，**每一格都請老師核對／訂正**，確認後才會寫進遊戲。
>
> - 「草擬示性式」= 待審欄；「SMILES」= 只給老師對照結構用，**不會**出現在遊戲畫面。
> - 訂正方式：直接在「草擬示性式」上改，或在「備註」寫指示即可。
> - 全 81 個分子，13 類。

## 先請老師定的三個通則

這幾個決定會套用到整份表，先確認可省去逐格重改：

1. **烷基要用哪種寫法？** 兩種都對，遊戲會統一用其中一種：
   - (A) 展開式：乙醇 `CH₃CH₂OH`、乙酸乙酯 `CH₃COOCH₂CH₃`
   - (B) 簡併式：乙醇 `C₂H₅OH`、乙酸乙酯 `CH₃COOC₂H₅`
   - 本表**先用 (A) 展開式**草擬（對高一學生較好認官能基）。若要改 (B) 請圈一下。

2. **環狀分子怎麼呈現？** 環己烷、環丙烷、環己烯、環氧乙烷、環己醇、環己酮這 6 個，
   線性示性式表達不易。三個選項，請老師擇一（本表暫記為「⚠環狀」待定）：
   - (甲) 這類**不放進示性式關卡**（環狀分子仍走原本的結構圖關卡）。
   - (乙) 用「分子式＋(環)」呈現，如環己烷 `C₆H₁₂(環)`。
   - (丙) 老師另給慣用寫法。

3. **苯環要用 `C₆H₅–`（苯基）還是畫環？** 本表一律用 `C₆H₅–`／`C₆H₄<`（鄰間對）文字寫法，
   苯本身寫 `C₆H₆`。若老師想改成別的表示法請註明。
