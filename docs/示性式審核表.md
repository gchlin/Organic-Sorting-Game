## 收錄原則：示性式要「實用」

這個關卡的精神是「**從文字裡的結構去想像分子結構**」。凡是示性式寫出來也想像不出結構、或課本實務上根本不用示性式表示的分子，**一律不收**。依此原則已排除：

| 排除的 | 數量 | 理由 |
|---|---|---|
| 烷基簡併寫法（`C₂H₅OH`） | — | 一律改用**展開式** `CH₃CH₂OH`。簡併了就看不出結構。 |
| 環狀分子（環己烷、環丙烷、環己烯、環氧乙烷、環己醇、環己酮） | 6 | 線性示性式（如 `C₆H₁₂(環)`）表達不出環，不實用。 |
| 萘 `C₁₀H₈` | 1 | 融合雙環，課本不會用示性式寫它。 |

原 81 → **74**。

> ⚠️ **這 7 個分子只是不進「示性式關卡」，仍留在原本的結構圖關卡**，不是從遊戲刪掉。

**苯保留**：苯 `C₆H₆`／苯基 `C₆H₅–`／`C₆H₄<`（鄰間對）是課本最標準、最常用的示性式寫法，甲苯 `C₆H₅CH₃`、苯酚 `C₆H₅OH` 全靠它。這是實用慣例，不是勉強拼湊，故不比照環狀排除。**若老師不同意請直接劃掉。**

## 順反／光學異構物：全部掃過，本題庫幾乎沒有

**示性式寫不出立體資訊**——順式與反式的 1,2-二氯乙烯，示性式都是 `CHCl=CHCl`，完全相同；旋光異構物亦然。所以這類分子本來就不該進示性式關卡。

我把全部分子掃過一遍，結果是：

| 類型 | 本題庫的情形 |
|---|---|
| **順反異構物** | **只有 2-丁烯** `CH₃CH=CHCH₃` 具備順反條件。其餘的烯（乙烯、丙烯、1-丁烯、1,3-丁二烯、苯乙烯、氯乙烯）雙鍵碳上都帶兩個 H，**不可能有順反**。 |
| **光學異構物** | **一個都沒有**，無任何掌性碳。<br>易誤判的兩個其實不掌性：2-丙醇 `CH₃CH(OH)CH₃` 中心碳接了**兩個相同的 CH₃**；甘油 `HOCH₂CH(OH)CH₂OH` 中心碳接了**兩個相同的 CH₂OH**。 |

**所以沒有東西要刪**——資料庫裡沒有任何標定順反或旋光的分子（2-丁烯只收一筆、不分順反）。2-丁烯以「不分順反」的一般式收錄，判分類（烯）不受影響。

> **異構物專題關卡（未來）**：若要做，**必須新增分子**才辦得到——順反至少要補「順-2-丁烯／反-2-丁烯」配對，光學要引入掌性分子（如 2-丁醇、乳酸）。且它是**另一種題型**（問「這是 E 還是 Z／R 還是 S」，不是問官能基），要走結構圖、需要新的答案池與題目引擎。列為獨立專案，**請老師一併給意見：值得做嗎？該收哪些分子？**

# ② 示性式讀法教學（新寫，待審）

> **為什麼要新寫**：現有的關卡教學是為**結構圖**寫的，內容是「有塗色（標色）的就是官能基」——直接指著彩色結構圖講話。**示性式關卡是純文字，這些教學完全用不上**，必須重寫一套。
>
> 而且「怎麼從文字讀出官能基」本身就是這關要訓練的技能，**教學就是關卡的核心**，不是附屬品。

## 教學第 1 頁：示性式在說什麼

示性式就是**把碳鏈照順序寫成一行字，並且把官能基原封不動露出來**。
例如乙醇 `CH₃CH₂OH`：碳 → 碳 → 一個 OH 掛在末端。你不用看圖，光讀這行字就知道分子長什麼樣。

所以讀示性式只有一個訣竅：**在字串裡找出官能基那幾個字**。

## 教學第 2 頁：一眼認出的官能基

| 在式子裡看到 | 就是 | 例 |
|---|---|---|
| 全部只有 `CH₃` `CH₂` `CH`，沒有 = ≡ O N 鹵素 | **烷** | `CH₃CH₂CH₃` |
| 碳與碳之間有 `=` | **烯** | `CH₂=CH₂` |
| 碳與碳之間有 `≡` | **炔** | `CH≡CH` |
| `C₆H₅–` 或 `C₆H₄`（苯環），且沒有其他官能基 | **芳香烴** | `C₆H₅CH₃` |
| `–OH` 接在碳鏈上 | **醇** | `CH₃CH₂OH` |
| `–OH` 直接接在苯環上 | **酚** | `C₆H₅OH` |
| `O` 夾在兩個碳中間（O 上沒有 H） | **醚** | `CH₃OCH₃` |
| `–NH₂`／`–NH–`／`–N<` | **胺** | `CH₃NH₂` |
| `–Cl` `–Br` `–I` `–F` | **鹵化物** | `CH₃Cl` |

## 教學第 3 頁（最重要）：CO 後面跟什麼？

文字上最容易混的是這四個——它們都是「C 和 O」，長得很像：

| 示性式 | 讀作 | 分類 |
|---|---|---|
| CH₃**CHO** | CO 後面跟著 **H** | **醛** |
| CH₃**COOH** | CO 後面跟著 **OH** | **羧酸** |
| CH₃**COO**CH₃ | COO 後面**還有碳** | **酯** |
| CH₃**CO**CH₃ | CO **兩邊都是碳** | **酮** |

> **口訣：看 CO 後面跟什麼——跟 H 是醛，跟 OH 是酸，跟 O–C 是酯，兩邊夾碳是酮。**

## 教學第 4 頁：另外兩組易混

- **醇 vs 酚**：都有 `OH`。`OH` 掛在**碳**上是醇（苯甲醇 `C₆H₅CH₂OH`，OH 掛在 CH₂ 上）；`OH` 直接掛在**苯環**上是酚（苯酚 `C₆H₅OH`）。**中間有沒有隔著碳，是唯一的差別。**
- **醇 vs 醚**：都有 `O`。醇的 O **帶著 H**、在末端（`CH₃CH₂OH`）；醚的 O **不帶 H**、夾在兩個碳中間（`CH₃OCH₃`）。

# ③ 各類「答錯提示」文案（新寫，待審）

> 學生答錯時，導師（魔導書）會說這句話。原則：**只指路、不直接給答案**，並且全部用**文字**描述（不能提「顏色」「圖上」，那是結構圖關卡的說法）。

| 類別 | 答錯時的提示 |
|---|---|
| **烷** | 再讀一次這行字：有沒有 `=`？有沒有 `≡`？有沒有 O、N 或鹵素？如果通通沒有，只剩 CH₃、CH₂、CH，那它就是最單純的烷。 |
| **烯** | 找 `=` 這個記號。要注意：`=` 一定要在**碳和碳**之間才是烯；如果是 C 和 O 之間的雙鍵，那是別的官能基。 |
| **炔** | 找 `≡`（三條線）。碳與碳之間的參鍵，就是炔的招牌。 |
| **芳香烴** | 看到 `C₆H₅–` 或 `C₆H₄` 就是苯環。但別急——**要確認苯環後面沒有掛別的官能基**。掛了 OH 就變酚，掛了 COOH 就變羧酸。 |
| **醇** | 找 `OH`。找到之後問自己：它掛在**碳**上，還是直接掛在**苯環**上？掛在碳上才是醇。 |
| **酚** | `OH` 要**直接**寫在 `C₆H₅` 或 `C₆H₄` 的後面才是酚。若 OH 和苯環之間還隔著一個碳（像 `C₆H₅CH₂OH`），那是醇不是酚。 |
| **醚** | 找那個**夾在兩個碳中間的 O**（`C–O–C`），而且它身上**沒有 H**。有 H 的 O（也就是 OH）是醇，不是醚。 |
| **醛** | 找 `CHO`。關鍵是 CO 後面跟著一個 **H**——這個 H 就是醛跟酮的分界線。 |
| **酮** | 找 `CO`，然後看它的**左右兩邊**：如果兩邊都是碳，就是酮。若 CO 後面跟的是 H（`CHO`）那是醛，跟的是 OH 那是羧酸。 |
| **羧酸** | 找 `COOH`——CO 後面跟著 OH。這四個字連在一起就是羧酸，少一個都不是。 |
| **酯** | 找 `COO`，然後看它**後面還有沒有碳**。`COOH`（後面是 H）是羧酸；`COO` 後面接碳（像 `CH₃COOCH₃`）才是酯。 |
| **胺** | 找 `N`。不管它是 `NH₂`、`NH` 還是 `N`，只要氮接在碳上，就是胺。 |
| **鹵化物** | 找 `Cl`、`Br`、`I`、`F`。看到鹵素就是鹵化物——即使式子裡同時有 `=`（像氯乙烯 `CH₂=CHCl`），本遊戲仍以鹵素為準。 |
